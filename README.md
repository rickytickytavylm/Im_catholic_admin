# ЯКатолик — редакция

Админка портала: витрина живого сайта, правка новостей, статей, видео, аудио, афиши, фотостока и блоков «О Церкви» / «Духовная жизнь».

## Открыть

Файл `index.html` — сразу внутрь редакции.

Локально удобнее через сервер:

```bash
npx --yes serve . -p 5174
```

Затем http://localhost:5174/

На GitHub Pages картинки берутся с опубликованного портала `fides_web`.

## Телефон

Меню — кнопка «Меню» сверху. Карточки в два столбца, поля не меньше 16px, зона нажатия 44px, учтены safe-area iPhone.
